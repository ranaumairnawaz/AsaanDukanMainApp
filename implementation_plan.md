# Implementation Plan: MeriDukan - WhatsApp-First E-Commerce SaaS for Pakistani SMBs

Build a multi-tenant SaaS platform where merchants in Pakistan can create storefronts and manage orders via WhatsApp, hosted on Hostinger.

## User Review Required

> [!IMPORTANT]
> **XAMPP MySQL Instance**: The MySQL database is currently not running (connection refused on 10061). Please start Apache and MySQL from your XAMPP Control Panel before proceeding with execution.
>
> **Node.js Gateway Slot**: The WhatsApp gateway uses Baileys (a Node.js library) and will run as one of the 5 Node.js slots on Hostinger. In development, it will run locally on a custom port (e.g., 3000) and require its own running process alongside Laravel.
>
> **WhatsApp Number**: To test the WhatsApp gateway, you will need to scan the QR code generated by the Baileys server using a WhatsApp phone number. Please prepare a spare number if possible to avoid spam risk on your primary account.

## Proposed Changes

### Laravel 11 Backend & Multi-Tenancy Scoping

#### [NEW] [BelongsToTenant.php](file:///c:/XAMPP/htdocs/MeriDukan/app/Traits/BelongsToTenant.php)
A global Eloquent scope trait to enforce `tenant_id` scoping on all business models automatically.

#### [NEW] [ResolveTenant.php](file:///c:/XAMPP/htdocs/MeriDukan/app/Http/Middleware/ResolveTenant.php)
Middleware to resolve the active `tenant_id` from:
1. Custom domain match
2. Subdomain match (if `subdomain_allowed` feature is active on tenant's plan)
3. Path prefix match (e.g., `/store/{slug}`)

#### [NEW] [PlanFeatureService.php](file:///c:/XAMPP/htdocs/MeriDukan/app/Services/PlanFeatureService.php)
A unified service to check if a tenant's subscription plan permits a specific feature (e.g., `analytics_enabled`, `product_limit`, `customer_whatsapp_notifications`).

#### [NEW] [FeatureRegistry.php](file:///c:/XAMPP/htdocs/MeriDukan/app/Services/FeatureRegistry.php)
A registry of all available plan features, their types (boolean, integer, decimal), and default values. Used to dynamically build the admin plan creator screen.

### Storefront & Theme System

#### [NEW] [ThemeRegistry.php](file:///c:/XAMPP/htdocs/MeriDukan/app/Services/ThemeRegistry.php)
A service to discover and load themes based on individual `theme.json` config files.

#### [NEW] [themes](file:///c:/XAMPP/htdocs/MeriDukan/resources/views/themes) (Directory)
Individual directories for the initial 4 themes:
- `fashion`: Lifestyle imagery, editorial feel.
- `cosmetics`: Elegant layout, soft color scheme.
- `electronics`: Spec-focused grid layout.
- `decor`: Warm, context-rich product display.

---

### Node.js WhatsApp Gateway

#### [NEW] [whatsapp-gateway](file:///c:/XAMPP/htdocs/MeriDukan/whatsapp-gateway) (Directory)
Standalone Node.js service using Baileys to manage the platform's WhatsApp connection pool.
- Exposes `POST /gateway/send`, `GET /gateway/status`, `POST /gateway/numbers`, and failover hooks.
- Configured to auto-reconnect from saved SQLite or JSON session data upon process starts.

## Verification Plan

### Automated Tests
- Run PHPUnit tests for tenant scoping: `php artisan test --filter=TenantScopeTest`
- Run PHPUnit tests for plan feature gate checks: `php artisan test --filter=PlanFeatureTest`

### Manual Verification
- **Storefront Display**: Set up test merchant store with different themes and check grid layout rendering on desktop and mobile viewports.
- **WhatsApp Gateway Failover**: Pair a backup number, trigger a manual failover in the Admin panel, and verify that subsequent messages route through the new active number.
- **Onboarding Flow**: Complete the onboarding wizard to ensure tenant configuration, database insertion, and theme settings are generated successfully.
